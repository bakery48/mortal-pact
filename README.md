## 動かし方

1. [Godot 4.3 以降](https://godotengine.org/) を用意する
2. Godot のプロジェクトマネージャから本リポジトリの `project.godot` を読み込む
3. ▶ 実行（メインシーンは `res://scenes/map/map.tscn`。ラン状態は autoload `Run` が管理）

### ランの流れ
- マップ画面で「進む」を押すと、現在地のノード（バトル / 休憩・ショップ）に挑戦する
- バトルに勝つと報酬で新しい魔物を獲得し、所持金を得る → マップへ戻る
- 休憩/ショップではHP回復か魔物の購入ができる
- ボスを倒すとフロアクリア → 次のフロアへ（敵が強化、デッキは継続）
- HPが0になるとゲームオーバー

### 戦闘の遊び方
- 下部に手札（魔物カード）が5枚並ぶ
- カードのコマンドボタンを押すとエネルギーを消費して発動
  - **ダメージ**：敵にダメージ
  - **与ダメージ+N**：このターンの与ダメージを加算（例：遠吠え）
  - **次2倍**：次のダメージコマンドを2倍（例：狂化）
- 使ったカードは捨札へ。エネルギーが続く限り行動可能
- 「ターン終了」で敵が予告どおりに攻撃 → 次のプレイヤーターンへ

### 合体（子孫生成）
- カードを使い込んで **⚔️成体** まで育てる
- 成体カードの「合体候補にする」を2枚押して選択 → ステータスバーの「合体 (2/2)」を押す
- 両親が消滅し、属性・コマンド・成長速度・レアリティを継承した子孫（🥚幼体）が手札に誕生する

## ディレクトリ構成

```
res://
├── project.godot           # メインシーン=map.tscn、autoload に Run を登録
├── scenes/
│   ├── battle/
│   │   ├── battle.tscn / battle_manager.gd   # 戦闘シーン・進行管理
│   │   ├── card.tscn   / card.gd             # カードUI
│   │   └── enemy.tscn  / enemy.gd            # 敵UI
│   ├── map/
│   │   └── map.tscn    / map.gd              # ランマップ（メインシーン）
│   └── ui/
│       ├── reward.tscn / reward.gd           # 戦闘報酬（カード獲得）
│       ├── shop.tscn   / shop.gd             # 休憩・ショップ
│       ├── result.tscn / result.gd           # クリア / ゲームオーバー
│       └── settings.tscn / settings.gd       # 設定（音量・フルスクリーン）
├── scripts/
│   ├── command_data.gd     # コマンド（技）リソース定義
│   ├── monster_data.gd     # 魔物カードリソース＋ライフサイクル
│   ├── deck_manager.gd     # 山札/手札/捨札の操作
│   ├── monster_factory.gd  # 初期デッキ・魔物カタログ(46種)・合体ロジック
│   ├── enemy_database.gd   # 敵・ボスのカタログ（行動パターン付き）
│   ├── run_state.gd        # ラン全体の状態管理（autoload "Run"）
│   └── audio_manager.gd    # BGM/SE 管理（autoload "Audio"、SEは手続き生成）
├── resources/
│   └── monsters/           # 魔物データ（.tres カスタムリソース）
└── assets/
    ├── sprites/            # （ドット絵を配置予定）
    └── audio/              # bgm_battle.ogg / bgm_map.ogg を置くとBGM再生
```

### サウンド・設定
- 効果音(SE)は `audio_manager.gd` が起動時に波形を生成するため、アセット無しでも鳴る
- BGMは `assets/audio/bgm_battle.ogg` `assets/audio/bgm_map.ogg` を置けば自動再生（無ければ無音）
- マップの「設定」から音量（マスター/BGM/SE）とフルスクリーンを調整でき、`user://settings.json` に保存される

### セーブデータ
- `run_state.gd` が `user://savegame.json` にラン状態を JSON 保存・復元する
- `MonsterData` / `CommandData` の `to_dict()` / `from_dict()` でカードを直列化（成長段階・EXP・属性・コマンドまで保存）
- マップに戻るたびに自動セーブ。戦闘途中で終了した場合は、そのノードの開始時点から再開する

### データ管理
- 魔物・コマンドは `Resource` を継承したカスタムリソース（`MonsterData` / `CommandData`）
- 初期デッキは `resources/monsters/*.tres` から読み込み、見つからない場合は `MonsterFactory` がコードから生成
- 各カードはドロー時に複製され、独立したインスタンスになる。`exp` と `stage` を各カードが保持し、個別に成長・老化する

### ライフサイクルの調整
段階の閾値・能力倍率・コスト補正は `scripts/monster_data.gd` の定数
（`STAGE_THRESHOLDS` / `STAGE_MULT` / `STAGE_COST_DELTA`）で一括調整できる。
初期デッキは「生まれたて」の幼体から始まり、使い込むほど成長してピーク（成体）に達し、
さらに使うとやがて老体・消滅へ向かう。成長は速く、老化は長いランをかけて進む設定。
